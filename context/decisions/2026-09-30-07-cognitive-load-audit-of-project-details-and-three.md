# 2026-09-30 - Cognitive load audit of project details, and three shell changes approved

- **Sept 30 2026: a cognitive load audit of the project details page was run, and the designer approved three shell changes to build next. Nothing in the product was changed.**
  - **Audit:** `context/reports/2026-09-30-project-details-cognitive-load-audit.md`. Scope: the four tabs of the project page template plus the record panel, for BioData Admin, Registered User and Public User, on Adelaide Hills and Coorong. Measured in headless Chromium at 1708x1024, and judged against the cognitive-load principles in `ref-shell.md` and CONTRACTS 4.3. Baseline is the page before the changes below.
    - **Headline findings:** five navigation systems at once with 22 keyboard stops before content; facts restated (status, name, published by, counts, coordinates); a hero with a state and two or three next steps; a Project tab of 3.5 screens; an amber "Details needed" card per missing group on sparse projects.
    - **Not done:** any fix. No user testing. A "coloured accents" measure failed and is not reported. The "Not ingested" chip is a prototype setting per the designer and is out of scope.
