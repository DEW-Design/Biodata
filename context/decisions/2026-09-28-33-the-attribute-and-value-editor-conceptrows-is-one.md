- **Sept 28 2026: the attribute and value editor (`ConceptRows`) is one card per attribute, per page feedback ("can we elegantly handle the attribute and the value bit? It looks so bad right now").** Each row was a two-column grid: the attribute select and the value field side by side under column labels, a disabled trash button when only one row existed, and for Location the value column only said "Add the areas below" while the areas editor sat underneath. Now each attribute is a bordered card: a heading ("Attribute 1", "Concept 1"), a remove button only when there is more than one, the attribute select (named by the heading, so no second label), then its value full width below it. The value follows the attribute's type: a multi-select, a select, Yes or No, a From and To date pair side by side, a text field, "Withheld entirely. There is no value to set." for a concept with no value, and for Location the areas editor itself. "Add attribute" is a secondary button. Fixed once in `app/pages/project-registration/concept-rows.tsx`, so it applies to every caller: the nomination form, Add Project option 2's species and metadata restrictions, and (by the shared file, not by an edit to it) the teammate's project-detail option 3 restriction editor.
