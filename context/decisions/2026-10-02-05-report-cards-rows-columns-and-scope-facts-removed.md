# 2026-10-02 - Report cards: Rows, Columns and Scope facts removed

- **Oct 2 2026: Report cards: Rows, Columns and Scope facts removed.** The designer asked, off a screenshot of the Data Ingestion report's card, what the rationale for Scope was and how Rows and Columns were relevant. They answered: remove Rows and Columns, keep Latest record, and were "not sure the scope is relevant at all".
  - **Why they went:** Rows restated the table footer ("1 - 50 of 76") and was inconsistent, hidden on the reports that had another total; Columns restated the Columns button and supports no decision. Both were added to fill the facts row of the 1Password-style card (2026-10-01-18), not because the data needed them. Scope was the nearest honest stand-in for 1Password's "Report by / Created" (the app has no report author or date); for a BioData Admin it repeated the description ("All uploads" under "Every dataset upload...").
  - **Scope removed too:** taken from "not sure it is relevant at all", on the reasoning that a non-admin's smaller row count is already explained by the rows being what that role may see. It is easy to bring back (a `scope` prop on `DataReport` and one `HeroMeta`); say if non-admins should have it.
  - **Built:** `DataReport` (`report-table.tsx`) no longer renders Scope, Rows or Columns, and the `scope` and `showRows` props are gone from it and from all nine reports; the empty Data Validation Error hero shows no facts. What is left in a card: Latest record where rows carry a date, and the report's own totals (Datasets, Events, Occurrences, Observations; Ingested, Total, Clean and With errors). The card is shorter, so the table gains about 40px.
  - **Contract:** CONTRACTS 4.6 item 4 now names those facts and says nothing in the card restates the table (no row count, no column count, no scope line). Rules regenerated.
  - **Verified:** `tsc`, `eslint` on `app/pages/_shared/reports`, `check:contracts`; live as BioData Admin and a registered user on all nine reports: only the intended facts show, tables and counts unchanged, no page scroll, zero console errors.
  - **Open:** whether the two ingestion reports should show real totals in place of the removed facts (Uploads, Failed validation, Awaiting review); not built. Not committed.
