- **Sept 29 2026: product-wide type audit run, per direct request ("Run it, please"). Report at `audit/type-audit-2026-09-29.md`. Nothing was changed; every fix waits for a decision.**
  - **Method:** computed styles measured live on 19 screens (15 product, 4 docs; registered, BioData Admin and public on Home) plus a source pass over every type class in `components/**` and `app/pages/**`, checked in the 2.9 order (design system, existing patterns, then `/emil-typography` and `/emil-design-foundations`). Zero console errors. The dev toolbar (system-ui) and Leaflet controls (Helvetica Neue) are not ours and were excluded. Product UI is Barlow only, 59 distinct size, weight, line-height, tracking, case and colour combinations.
  - **System-level findings:** (1) `text-md` is undefined, so 63 live uses inherit 14px/21px: Input md and lg are identical, Button lg and xl equal md, Tab md is 21px against sm 20px, and the docs list it as 16/24. (2) The docs scale disagrees with the code (xs 12/18 vs 12/16, xl 20/30 vs 20/28, display tokens have no line height or tracking, display weight 600 vs hero 500, captions Medium vs Regular). (3) `text-quaternary` (#8f8b87) is 3.4:1 on white and is used for inactive tabs, table headers, eyebrows and footer links. (4) Barlow italic is not loaded and `font-synthesis: none` is absent, so every scientific name is a faux italic. (5) 10px text in the rail badge, org pill, Primary chip and avatar count.
  - **Same role, different treatment:** card and section headings at eight size and weight pairs (medium vs semibold, the docs say semibold); table plain columns mixing secondary and tertiary; six count badge treatments; six KPI value shapes; 12 hand-copied MetaField variants; read-only values regular in some records and medium in others; label column 176px vs 224px.
  - **Open decisions D1 to D12** are in the report with a recommendation each. Recommended order: `text-md` (after a Figma check of the Input, Button and Tab frames), quaternary contrast, Barlow italic, then heading weight and table cells, then KPI, MetaField and count badge consolidation. Adding or changing a shared component or token waits for approval.
  - **Not covered:** mobile widths, hover, focus and disabled text states, Explore option 1, docs pages beyond typography and table. Not committed.
