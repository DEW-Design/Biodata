# 2026-10-05 - In production link opens as a role that has the feature, not on a restriction page

- **Oct 5 2026: In production link opens as a role that has the feature, not on a restriction page.** Follows `2026-10-05-05`. The designer, off a screenshot: viewing `/proto/column-2` as a Public user and following "In production" landed on `/pages/template-finder?userRole=public-user`, the "needs a free account" restriction message. "For public users - no. Like these situations, we need to default to where the feature exists and on what persona."
  - **Cause:** the link always kept the role being viewed. The Template Finder is closed to a public user (`templateFinder`), so the link led to the page's restriction state, which is right for someone arriving by URL but a dead end for someone checking a folded decision.
  - **Fix:** `PrototypeTools` asks the bar's own gate (`isPageBlockedFor`, the same one the role tool uses to take you Home) whether the viewed role can open the page. If not, the link opens it as the lowest role that can (walking `USER_ROLES` from the bottom), and the bar says so after the name: "In production Template Finder as Registered User". If the viewed role can open it, nothing changes and nothing is added.
  - **Verified (Playwright):** `/proto/column-2` as Public user links to `/pages/template-finder?userRole=registered-user` and lands on the list (8 rows); as Registered User and BioData Admin it keeps the role and shows no note; `/proto/layouts` as Public user opens the Data Validation Error report as Registered User; `/proto/tab-icons` as Public user keeps public-user (the project page is open to everyone). `tsc`, `eslint`, `check:contracts`; zero console errors.
  - **`CONTRACTS.md` 4.4** gains the sentence; `contracts-prototyping.md` regenerated.
  - **Limit:** only a page whose whole route is gated is detected (`wholePageGates` in `prototype-tools.tsx`); a control hidden inside an open page is not, so a lab about one would open the page as the viewed role.
  - **Open:** none. Not committed, not pushed.
