# 2026-11-16 - Help icon on record field names that need explaining

- **Nov 16 2026: Help icon on record field names that need explaining.** The designer, with a screenshot of a site record's Location information, Photopoint and Site scores cards: "for all the complex field names, could we show a small info icon on hover and the hover opens with a popup that shows the description ... only for the ones needed, not for easily understandable field names, for example Observers."
  - **What changed.** `FieldRow` (`app/pages/project-detail/field-notes.tsx`) shows a `HelpCircle` after a field's name when `fieldHelp(label)` (`app/pages/project-detail/field-help.ts`) has an entry. It appears on row hover or keyboard focus, like the row's edit icon, and always where the pointer is coarse (no hover on touch). Pointing at it or focusing it opens the design system `Tooltip` (title the field's name, description the text). Every record card that draws a `FieldRow` gets it from the one map, keyed by label.
  - **Borrowed from:** the design system `Label`'s `tooltip` (the same `HelpCircle`, `Tooltip` and `TooltipTrigger`, `text-fg-quaternary`), and the row's own hover reveal. No new component and no new type layer: the tooltip's text is the component's own.
  - **Structural fix that came with it.** A field with notes was one `<button>` around the whole row, so a help button in the label would have been a button inside a button. The toggle is now an empty button over the row from behind (`absolute inset-0`, `data-row-toggle`), and any button or link inside the row is lifted above it. A click anywhere else on the row still opens the notes. This also stops a link in a value (the landscape score link) being nested in the toggle.
  - **Which fields (20), and where each line comes from (0.3):** the Darwin Core term each field maps to (Location method, Datum, Reliability, Sample site dimensions, Occurrence status, Voucher number, Determination date, Determiners), the field's code list or limits (Date accuracy, Determination date accuracy, Reliability, Photopoint direction, Visit sequence number), IBRA (region, subregion), NSX (ref-domain.md), and the BAM scoresheet comments in `site-scores/*.ts` and `landscape.ts` (the five site scores). The wording is a draft for a content review.
  - **Verified:** `tsc`, `eslint` on both files, `check:contracts` OK. Live in Chrome as BioData Admin on Cleland Stringybark Woodland: 9 help icons on the site, none on plain names; hidden at rest (opacity 0), shown on row hover; tooltip opens on Datum and on Reliability (a noted row); a click elsewhere on Reliability still opens its notes (`aria-expanded` true); the icon's hit area 40 x 40; no `button button` in the DOM; no console errors. Not checked: touch emulation, keyboard-only pass, the Site scores tiles at the top of the card (they are not `FieldRow`s and have no icon).
  - **Open, for the designer:** (1) help text for fields nothing in the repo defines: Photopoint disc number, Photopoint marker present, Legacy site ID, Source ID, Event array, Institution rego #, Legacy sighting #, Species seq no., Transfer date, Mud map; (2) whether the score tiles at the top of Site scores get the icon too; (3) `HelpCircle` (the design system's field-help glyph) or an `InfoCircle` as asked; (4) whether the same help shows in edit mode. Not committed.
