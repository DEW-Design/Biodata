# 2026-10-01 - Button utility aria-label fix, text-editor buttons moved onto ButtonUtility, typography re-check

- **Oct 1 2026: Button utility aria-label fix, text-editor buttons moved onto ButtonUtility, typography re-check.** Follow-up to `2026-10-01-35`, on the designer's answers to its three open items.
  - **Component fix:** `ButtonUtility` now sets `aria-label` to `props["aria-label"] ?? tooltip` after the spread, so a caller passing an explicit `undefined` no longer drops the tooltip's label. The doc playground passes `aria-label={previewTooltip ? undefined : "Edit"}` again, which exercises it; verified in the browser (label "Edit").
  - **Migration (1.3):** the text-editor's internal `EditorButton` (`text-editor-button.tsx`) is removed; every toolbar and bubble-menu control is a `ButtonUtility` (`color="tertiary"`, `size` sm). Measured 32x32, 6px radius, 20px icon, same colours as before; the "on" state is `bg-primary_hover text-fg-secondary` passed through `className`; Enter toggles bold from the keyboard; disabled is 50% opacity (before it was only a not-allowed cursor). OVR-006 is set to `retired` and the file left the component inventory.
  - **Other icon-only buttons, deliberately not migrated:** about 35 icon-only buttons under `app/pages` are already the DEW `Button` (36px for sm, 40px for md), and `ButtonUtility` is 32px, so swapping would shrink them on every screen; the photo carousel chips, the stacked map zoom control and the column chooser's drag handle are different patterns; `projects/page.tsx` and `projectsv2/page.tsx` are the stale drafts. Whether the `Button` icon-only cases should move is a designer decision.
  - **Typography re-run (`/emil-typography`, `/emil-design-foundations`):** the button-utility and text-editor doc pages measure identical to the textarea page for h1, h2, intro paragraph, section label, code, table head and cells (Geist doc chrome, `text-wrap: balance` on the prose). The tooltip is Barlow 12px/16px semibold white on gray-950, unchanged `Tooltip`. Text-editor content, label and hint measured against `TextArea` earlier (`2026-10-01-33`). Fixed: three-dot ellipses in the editor's default placeholder and the doc page are now the `…` character.
  - **Verified:** `tsc`, `eslint` on the touched files, `check:contracts`; live browser over both pages, zero console errors. Not re-tested: narrow widths, the privileged roles.
  - **Open:** the `Button` icon-only sizing question above. Not committed.
