# 2026-10-01 - What is a project becomes a walkthrough modal

- **Oct 1 2026: What is a project becomes a walkthrough modal.** Page feedback on the explainer card (decision `2026-10-01-11-*`): it takes too much space, brevity is key, none of it needs to exist on the page; what if it were a walkthrough modal. The card is removed from the Projects list and the content is now a `WalkthroughModal` (`app/pages/_shared/walkthrough-modal.tsx`), built from the design system's modal (`ModalOverlay`, `Modal`, `Dialog`), `FeaturedIcon` and `Progress.MinimalIcons`: one step at a time (a large icon, a small "What is a project? . 1 of 5" heading, the step title and one line, step dots), Back and Next, Done on the last step with the one "Open resources and user guides" link above the dots, and the modal's close X. Five steps: Project (carrying the definition), Site, Visit, Occurrence, Observation, with the records-tree icons and the same one-line copy as the card (still drafted, still to be content reviewed). It opens by itself when the list loads, once per page load (a module-level record, so moving between All and My projects does not bring it back and a reload does, for the demo), and a "What is a project?" help button (secondary, with the `HelpCircle` icon, per 3.12) in the section header opens it again from the first step. Shown to every role except BioData Admin (`showsProjectExplainer`), a signed-out visitor included. Typography sources (2.9): the step title and description take the empty state's centered icon, 18px / 600 title and 14px tertiary line; the small heading is the section-label style the explainer card used. Keyboard: Next has focus when it opens (Enter steps through), Escape and the X close it, and the dialog is named for the subject. The `ExplainerCard` stays, for the short one: nominations' "How a nomination is reviewed". Docs: the banners pattern page gains a "Walkthrough modal" section with a live example, and the card section no longer claims Projects; CONTRACTS 3.10's "where the information goes" now names the three (a short explainer card, a walkthrough modal for a longer one or one on a dense list, a page banner), regenerated into the rule files; `ref-shell.md`, `nav.ts` and the README updated.
