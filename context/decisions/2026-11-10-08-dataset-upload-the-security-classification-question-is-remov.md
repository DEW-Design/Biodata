- **Nov 10 2026: the Data upload acknowledgement no longer asks for a security classification.** The designer, with the updated screen (step 3 of 3 shows Data licence, First Nations considerations and Privacy and restriction): "Make sure the security classification question is removed from dataset upload screen." Datasets already saved in a browser keep an unused `classification` key in localStorage, which nothing reads.
  **Not touched.** The notification form's "Classification" (a different field, the email's marking) and the nomination and taxonomy uses of the word.
  **Verified.** `tsc` and `eslint` on the dataset-upload folder, the datasets view and the Datasets step: clean. Live as a Registered User on `/pages/project-list/adelaide-hills/upload`: step 3 shows Data licence, First Nations considerations and Privacy and restriction and no classification; confirming with nothing answered lists "Data licence, First Nations considerations, Privacy and restriction confirmation"; answered, it uploads and lands on the project page; zero console errors.
