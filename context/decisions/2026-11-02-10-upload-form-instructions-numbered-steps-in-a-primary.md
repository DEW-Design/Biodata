  - **Borrowed (0.9).** The design system already has a true circle for a short number, `CountBadge` (`components/base/badges/badges.tsx`, 20px, `gray`, `brand`, `error`), and the primary fill is `bg-brand-solid` with `text-fg-white`, the Progress steps' marker for a completed step. The Progress number step was not used: it marks done and to do (a tick, a focus ring on the current step), which a list of instructions is not. No new component was made (1.4).
  - **Changed.** `CountBadge` takes `color="brand-solid"` (an additive value, 1.6; the other colours are unchanged). The upload form's instructions (`app/pages/_shared/dataset-upload/upload-form.tsx`) are a list of `CountBadge count={i + 1} color="brand-solid"` beside the text, 12px apart, the circle top-aligned with the first line (the text is 14px on a 20px line, so a 20px circle sits on it). Both kinds of data have it (two steps for structured, three for unstructured), because it is one list. The words are unchanged. The list keeps its `ol` (with `role="list"`, since `list-none` removes it in Safari) and the circle is `aria-hidden`, so a screen reader hears the list and its length once and does not read each number twice. The text carries `text-balance` where it wraps (2.3). The three lines of text moved into one `uploadInstructions` record keyed by data kind.
