# 2026-10-01 - Modal and shared component buttons carry icons

- **Oct 1 2026: Modal and shared component buttons carry icons.** Page feedback on the DLA Approve request modal: same as the record actions, modals need icons on their buttons; not icon overload, but wherever there is an action it has an icon, as a more visual way to learn and set behaviour patterns. The check added in decision `2026-10-01-13-*` only walked `app/pages`, so it missed every button that a shared component renders (the same gap found twice, so the check was extended, section 0.8). Sweep of `components/**` for text buttons without an icon: the three modals (`ConfirmationModal`, `DestructiveModal`, `FormModal`), the button-style alert (`AlertFullWidth` confirm and dismiss), the file field's Browse, multi-select's Reset and Select all, and the simple table pagination's Previous and Next. Changes, all additive props (1.6): the modals take a required `confirmIcon` / `submitIcon` (an action is never the same twice, so no default, and tsc listed all 27 call sites) and a `cancelIcon` defaulting to `XClose`; `FormModal` takes `submitIconTrailing` for Continue; `DestructiveModal` takes `secondaryIcon` defaulting to `Save01` (its one secondary is Save draft); "Keep editing" and "Keep restriction" pass `ArrowLeft`; the discard, delete and remove prompts use `Trash01`, cancelling an agreement or request `SlashCircle01`, approve and accept `CheckCircle`, re-generate `RefreshCcw01`; `RejectModal` takes a `submitIcon` (default `XCircle`, the nomination return passes `MessageAlertCircle`); User Management's status-change confirm uses the action's own icon. `AlertFullWidth` takes `confirmIcon` and `confirmIconPosition` (button-style only; link-style actions stay icon-free) and its dismiss button gets `XClose`; `PageBanner` requires an `actionIcon` (an arrow after the label for Go to DLA, a person for Sign up for access). Browse takes `Upload01`, Reset `RefreshCcw01`, Select all `CheckDone01`, Previous and Next an arrow each. The modal docs (API rows, usage snippet, examples) and the banner docs were updated. CONTRACTS 3.12 gains the modals and shared components paragraph, rows for Keep editing, Discard, Re-generate and Select all in the icon table, the second origin, and widened enforcement; `AUTO §3.12` now also walks `components/application`, `components/base` and `components/custom`, proved with a temporary file in `components/base` (caught) and removed. Verified live as BioData Admin and Registered User: the Approve request modal from the screenshot (Browse, Cancel and Upload and Approve all with icons), DLA Reject and Cancel request, the DSA discard prompt (Keep editing, Save draft, Discard changes), User Management's status confirm, and the Explore banner's Go to DLA; zero console errors. tsc, eslint on everything touched, check:contracts and the build pass. Open: the demo triggers on the docs pages (Leave page, Delete project, Invite member) are doc chrome outside the check and have no icons; the confirm icons on the two neutral discard prompts (`ConfirmationModal`) are a bin, like the destructive ones, for one icon per action. Not committed.
