# 2026-10-15 - Report controls lab: the Flora Taxonomy Report with its parameters as the Filter menu, a popover, or today's grid

- **Oct 15 2026: Report controls lab, `/proto/report-controls`.** The designer, off a screenshot of the Flora Taxonomy Report: "see how the controls occupy almost 50% of the screen leaving only 50 for the content. Content might be more important than controls. Can we find a better way to optimise this? /mobbin for patterns", then "Bring this into proto first before we fold that into production." Strictly a lab: the production page is unchanged (checked: the grid of parameters, the table at 601px, no Parameters button).

  **The problem, measured** at 1440 x 1024: app header 65px, back link and gradient card ~256px, tabs 48px, the labelled grid of parameters 156px, the toolbar 36px; the table starts 601px down (59%) and its area is 334px, 6 rows. The same problem was explored on 2 Oct (`2026-10-02-10-*`, `/proto/layouts`, Data Validation Error report): its options were never chosen, and its slim header (`DataReport header="line"`) is reused here.

  **Mobbin, what was taken as interaction and IA only (2.6):** parameters as one row of chips and popovers with an applied value as a removable chip (Docusign, Mercury, Whop, Navattic); a summary that opens (Google Ads, Mixpanel); a side drawer for heavy setup (Deel, Wrike; not built, because the design system has no slide-over); a slim report header (Toggl, Navattic, Klaviyo). Nothing of their styling was used.

  **The four options**, on the real report in the real shell, every tab, chosen on the Prototype tools bar (`?option=`), whose Controls entry reads the table's real position and size in the window:
  - **A Today.** The card, the grid of parameters. Table starts 601px down: 334px, 6 rows (800px tall: 127px, 2 rows).
  - **B Filter and search.** The card stays; there is no grid.   - **C B, slim header.** B with the title line in place of the card. Table starts 309px down: 634px, 13 rows (800px tall: 410px, 8 rows).
  - **D Parameters popover, slim header.** The grid kept as the sheet draws it, in a Parameters popover on the toolbar's row (two columns, a Reset at the foot), with what is set shown beside the button as chips and a count on the button. The same 309px, 634px, 13 rows.
