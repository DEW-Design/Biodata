- **Oct 16 2026: three changes to the Flora and Fauna Taxonomy Reports.** The designer sent a capture of the Project Audit Log ("just a capture of how the mockdata should look, this is the way we're adding stuff into the audit log for Flora Taxonomy record": three rows of Seq# 1 to 3, timestamp "16/10/2026 12:00:00 AM", NSX Code, Entity Type "Concept", Modified Entity "Genus", Previous Details "Accacia", Current Details "Accacia 1", "Accacia 2", "Accacia 3", Action "Split", Source Type "Portal") and asked for: (1) "I need Combine, Split, Append, and Rename rolled up in the audit log. Remove the split, append and rename tabs."; (2) "Let's rename 'Species Number' to 'NSX Code' on the audit log"; (3) "The table search: the result carries over to the other tabs as well, say I search for NSX Code P04411."

  **The audit log (both reports).** An entry is written the way the capture writes it (`taxonomy-audit-data.ts`): a Rename, Combine, Split or Append committed in Taxonomy Management is one row for each name it produced, so a Split into three is three rows; Entity type is "Concept"; Modified entity is the rank of the name (`rankOf`: Genus for one word, Species for two, Subspecies, Variety or Form from its last infraspecific rank); Previous details is the name before (a Combine joins every name it took in with " + ") and Current details the name after; Source type is "Portal"; the timestamp is "16/10/2026 4:42:09 PM" (Adelaide time, to the second). What a taxon records itself (created, edited) is Action Create or Update with the day written as its start ("12/03/2019 12:00:00 AM"), as the capture writes a day with no time. Source is "BioData Admin" (mock: Taxonomy Management is BioData Admin and above, and the Project Audit Log's Source is likewise the role); Source type and Source were empty before. The Flora sheet's "Species number" is now "NSX code" (the Fauna sheet already was). The Filter's Action attribute already lists Rename, Combine, Split and Append.

  **Tabs removed.** The Flora Taxonomy Report no longer has Rename species, Split species or Append species: it has seven tabs (List detail, SA regions, Aus / World, Reg herb data, Species attributes, Audit log, Species synonym). Removed with them: their hooks and columns in `taxonomy-management-tabs.tsx` (which is now Species synonym only), the change-log row builders and `SplitRow` in `taxonomy-management-data.ts`, and their three Example records in `taxonomy-example-rows.ts`. CONTRACTS 4.2e's list of tabs that show an Example record, the generated `contracts-shell.md`, the Reports landing description and the screen index are corrected. Combine had no tab; it is now in the audit log like the other three.

  **The search carries across tabs.** The search is the report's, not a tab's: `DataReport` takes an opt-in `keepSearch`, which `TaxonomyTabs` (taxonomy-tabs-shell.tsx, shared by both reports) sets, so changing `resetKey` keeps the search while the filters, sort and page still start again (each tab has its own facets and columns). Searching P04411 on List detail leaves "P04411" in the box on every Flora tab and narrows each (List detail 1 row, Audit log 1 row, the others "No ... match" with the usual way back); searching M01170 on the Fauna report does the same across its seven tabs. Every tab's search matches the NSX code. The export's "Species code & name" line reads the same search.
