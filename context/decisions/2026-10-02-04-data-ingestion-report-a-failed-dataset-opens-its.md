# 2026-10-02 - Data Ingestion report: a failed dataset opens its Data Validation Error report

- **Oct 2 2026: Data Ingestion report: a failed dataset opens its Data Validation Error report.** The designer said a dataset that failed validation should go to the Data Validation Error report, and that clicking into it goes there.
  - **Built:** in the Data Ingestion Report Pre-Flight Validation, the **Validation status** chip and the **Business rule failures** count of a run that has errors are links to `/pages/reports/data-validation-error?dataset=<id>`, with the role kept (`useRoleHref`). The Data Validation Error report already opened on `?dataset=`, so it lands on that dataset with its project and counts. A run with no errors (processing, or passed clean) shows its value as plain text. Which runs have errors is the report's own rule (`hasErrors`: validation Failed, or any business rule failure), so the two reports cannot disagree about it.
  - **Count included on purpose:** the designer named failed validation; a run that passed with some rows failing business rules also has a report of errors, and with the chip alone it had no way in. The count, red already, underlines on hover.
  - **Affordance:** hover dims the chip to 75% and shows a pointer; keyboard focus gets the 2px focus ring; the accessible name is "View the validation errors for DS-2026-01001". No native tooltip (not a DEW component).
  - **Keyboard:** the table's own model applies, as for the Download buttons in the same row: the row is the tab stop, Right arrow moves through the cells to the link, Enter opens it. Verified live.
  - **Verified:** `tsc`, `eslint`, `check:contracts`; live as BioData Admin (25 links: 4 Failed chips and the counts of runs with failures) and a registered user (13 links); a Successful run with zero failures has none; the click lands on the right dataset; zero console errors.
  - **Open:** the Data Validation Error report has no link back to the source upload in the ingestion report; the Record ID is not itself a link. Not committed.
