# 2026-10-01 - Scope switches list All before My

- **Oct 1 2026: Scope switches list All before My.** The designer asked for column 2's "My X / All X" to read the way the data is shaped: All first, because "My" is an applied filter on All. Reordered everywhere the pair appears: the shared `AgreementScopeNav` (DLA, DSA, nominations, so "All requests, My requests", "All agreements, My agreements", "All nominations, My nominations"), the Projects sidebar tabs (`projects-sidebar.tsx`, "All projects, My projects"; a public user still sees only All), and the two mobile-menu lists of the same scope (the project list page and the dashboard). Wording that named the old order was updated in the `/pages` index description, the page and shell comments, and `ref-shell.md` (the collection pattern now says All / My, and why). Nothing else changed: the `?scope=` values, the filtering and each role's default are as they were (All by default for DSA, for nominations and for a reviewer on DLA; My for a role that is not a DLA reviewer). Verified live: the tab order and the selected tab for BioData Admin, Registered User and Public User on DLA, DSA, nominations and the project list (nominations shows no switch to a non-reviewer, as before); on DLA, clicking "My requests" narrows 9 rows to 2 and puts `scope=mine` in the URL; zero console errors. The designer's wider idea, that "My" is a filter, is honoured as order only; turning it into a filter control in the table toolbar (with column 2 then holding only the section label) is a larger change and was not asked for. Open: (1) a Registered User sees an "All requests" tab on the DLA list and it lists all 9 requests from every organisation (other people's names and organisations), while their nominations list shows only their own and `dlaApproval` is admin only; whether a role that cannot review should get the All tab at all is an access decision for the designer; (2) with All first, the Registered User's DLA list still opens on the second tab (My requests), because that is their default. Not committed.
