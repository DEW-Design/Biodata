# 2026-10-16 - Fauna Taxonomy Report: five more tabs (Australian distribution, regional data, species reference, species attributes, audit log)

- **Oct 16 2026: five more sheets for the Fauna Taxonomy Report.** The designer sent five sheets (a title and metadata screenshot and a column list each): "BioData - Fauna Taxonomy list - Australian Distribution", "- Regional Data", "- Species Reference", "- Species Attributes" and "BioData - Fauna Taxonomy list Audit Log Report". Each is a tab of the same report (`/pages/reports/fauna-taxonomy`), built by `useSheetTab` like the first two, so the report has seven tabs in the sheets' order: List detail, Species status, Australian distribution, Regional data, Species reference, Species attributes, Audit log. Icons are those of a Fauna taxon's own tabs (`tx-records.tsx`): Globe01, MarkerPin04, BookClosed, List, with ClockRewind for the audit log as in the Flora report. Each sheet's metadata is the table's own search and Filter (CONTRACTS 4.6 item 4) and is written above the columns of Export CSV and XLSX (checked on Regional data).
  - **Australian distribution:** 10 columns, a row for each row of the taxon's Australian Distribution table (15 for the five sample taxa). Metadata: Species Code & Name, NSX Code, Region, Certain, NPW Act Status Desc, Date.
  - **Regional data:** 14 columns, a row for each row of its Regional Data table (10). Metadata: Species Code & Name, NSX Code, SA Status Desc, Australian Status Desc, NPW Act Status Code, NPW Act Status Desc, Date; the Filter also offers the SA region, Status, Cross boundary?, Certain?, Official?, Indigenous? and Accepted?.
  - **Species reference:** 7 columns, a row for each row of its Species Reference table. No Fauna taxon has one, so it shows one mock Example record (CONTRACTS 4.2e). Metadata: Species Code & Name, NSX Code, New Species No, Date.
  - **Species attributes:** 21 columns, the Flora report's attribute rows for the Fauna taxa (`attributeRowsFor`), ending with the four created and modified columns. No Fauna taxon has an attribute, so one mock Example record. Metadata as the Flora sheet's: Region Group, Region Name (the sheet's second "Region Group"), Attributes type, Date.
  - **Audit log:** 14 columns, the same events as the Flora report's (changes committed in Taxonomy Management, and the days and people a taxon records) for the Fauna taxa only (`useFaunaChanges`: a change that touched no Fauna taxon is left out); 10 rows for the five sample taxa. Seq#, Timestamp, NSX code, Species (the scientific name, italic), Common name, Entity type, Modified entity, Previous and Current details, Action, Source type, Source, User, Comments. The sheet's three blank columns before User are not drawn; Source type, Source and Comments are drawn and empty (the app records none).

  **Mock data (the designer, 16 Oct 2026: "this is a clickable prototype not a production screen").** The Fauna taxa's tables hold a region and a comment and nothing else, so what a sheet asks for beyond that is made up in the report from what the taxon holds, the same way every time and never stored (`fauna-taxonomy-place-data.ts`): Created by, Created on, Modified by and Modified on are the taxon's own; Indigenous? is the taxon's; Certain?, Official?, Accepted? and Cross boundary? are "Yes", "Yes", "Yes" and "No", and Status is "Current", because the wireframes do not say what their values are. A value the row itself holds wins. Taxonomy Management does not show any of it.

  **Departures from the sheets, each in the files' header comments.** Labels are sentence case and spelled out ("Attributes is Officical" is "Attribute is official?", "Certain" the column is "Certain?"). Regional Data's metadata lists "Australian Status Desc" twice, as the Species Status sheet's columns do: the second is read as the NPW Act status code. The Species Attributes sheet lists "Region Group" twice in both its metadata and its columns: the second of each is the Region name. The date filter on the table tabs reads the days the taxon carries (created, modified), because a table row has no date; on Species attributes it reads the Date of assessment.
