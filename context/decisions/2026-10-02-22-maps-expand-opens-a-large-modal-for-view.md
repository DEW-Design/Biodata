# 2026-10-02 - Maps: Expand opens a large modal for view maps; draw maps keep a takeover; one X to close; maps re-measure

- **Oct 2 2026: Maps: Expand opens a large modal for view maps; draw maps keep a takeover; one X to close; maps re-measure.** The designer approved the three recommendations made after asking "what if it was a modal instead of full screen?": a large modal for the view-only maps, the draw-on-map takeover kept but closed by an X at the top right, and the entry button renamed "Expand".
  - **Entry:** every map in a page (`ExpandableMap`) has an "Expand" button at its top left (the zoom buttons own the right), accessible name "Expand map: <what it shows>". It replaces "Full screen", which was wrong once the view is a dialog.
  - **View maps (project extent, a record's location, a nomination's obscured areas) open in the design system's Modal:** the page dimmed behind, a dialog inset about 32px (1600px at most, 1376 x 836 in a 1440 x 900 window), a title bar, the X in the corner as in every other modal (`CloseButton`, 16px in), and the map filling the rest. Closes with the X, Escape or a click outside; focus returns to Expand.
  - **Draw maps (the DLA "Add a location" map, which already sits in a modal) keep the whole-window takeover** (`presentation="takeover"`), with the title on the left, the draw tools at the right and the same X at the far right. The earlier "Exit full screen" button is gone, so there is one way to close every expanded map. The project registration location picker keeps its own expand, as before.
  - **A map bug found and fixed once, in `sa-map.tsx`:** Leaflet measures its box once, so the expanded map, which reaches its final size just after it mounts inside the animated modal, drew its circle cut off along a straight edge. A `ResizeSync` inside every map now re-measures when its container changes size, which also protects the other embedded maps.
  - **Not changed:** the record panel's and edit drawer's own "Full screen" toggles (they expand a panel, not a map). Say if those should be renamed too.
  - **Verified:** `tsc`, `eslint`, `check:contracts`; live: the project extent modal (X, Escape, click outside, focus return, the circle complete), a record's location, a nomination's areas, and the DLA takeover (draw tools and X, Escape back to the Add location modal); zero console errors.
  - **Open:** the project page's Geographic extent map is now larger in the modal than it needs to be for a single circle; a smaller modal size for it is possible. Not committed, not pushed.
