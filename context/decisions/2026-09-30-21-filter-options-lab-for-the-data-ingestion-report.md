# 2026-09-30 - Filter options lab for the Data Ingestion Report

- **Sept 30 2026: Filter options lab for the Data Ingestion Report.** The designer disliked the "Add filter" popover (a searchable list of attributes, decision 19): it opened over the chips it belongs to, its search field read as a form field rather than a menu, and the ninth attribute sat below the fold. They asked whether it should be styled as a contextual menu, and to prototype a few filtering options. New lab `/proto/filter-options` (`app/proto/filter-options/`), switched from the Prototype tools bar's "Layout" tool (`LayoutOptionSwitcher`, CONTRACTS 3.8 and 4.4), three directions on one axis, where the filter control lives: A a contextual menu (Filter button, attributes with icons, a submenu of values per attribute, dates as presets plus a custom-range popover), B quick filters (Validation status, Submission status, Project and Ingested as buttons that show their value and open a popover, the rest under "More filters"), C a filter panel down the right-hand side (design-system `Accordion variant="compact"`, a row count at the foot, chips only while the panel is closed). All three drive the same `useAttributeFilter` state, search, sort and table as the real report. To make that possible the report was split without changing what it does: `useIngestionReport` (state) and `IngestionReportView` (layout with `controls`, `summary` and `aside` slots), with `IngestionReport` composing the current attribute filter; `attribute-filter.tsx` now exports `OptionsPicker`, `DatePicker`, `summariseFilter` and `DATE_PRESETS`. The real report at `/pages/reports/data-ingestion` is unchanged (re-tested: filter, chips, empty state). Verified: tsc, eslint on the touched files, `check:contracts`, and a live Playwright pass over all three (filter, submenu, custom range, More filters, panel accordion, count badge) plus keyboard (open, arrows, Space, Escape one layer at a time, focus returns to the trigger), zero console errors. `npm run build` also passes and lists the lab route. Not yet done: a decision on which direction wins. Open: no direction chosen; when one is, it goes into `IngestionReport`, this folder and its `/proto` index line are deleted, and CONTRACTS 4.2d is rewritten for the winner. Not built, on purpose: filters in the table's column headers, and a search-first "type a value" token input. Not committed.
