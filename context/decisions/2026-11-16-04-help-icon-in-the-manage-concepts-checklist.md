# 2026-11-16 - Help icon in the Manage concepts checklist

- **Nov 16 2026: Help icon in the Manage concepts checklist.** The designer, with a screenshot of a site's Manage concepts menu: "Manage columns need help icons as well."
  - **What changed.** `SectionFieldsMenu` (`app/pages/project-detail/visibility-panel.tsx`): a concept with help text (`field-help.ts`) shows the record cards' `FieldHelp` icon after its name, on row hover or keyboard focus, always on touch; the same text and `Tooltip` as the cards. A concept with no help text shows nothing, as on the cards. The row's accessible name is the concept's name alone (`aria-label`), so the icon's "About ..." is not read into it.
  - **A press on the icon does not tick the row.** The menu row takes its press from the pointer events under it, so a press on the icon toggled the concept off (found live: Datum went to unticked and the count to 6/7). The icon's wrapper stops pointer down, pointer up, mouse down and click.
  - **Verified:** `tsc`, `eslint`, `check:contracts` OK. Not checked: a screen reader, touch emulation.
