# 2026-09-25 - a "Pages build" check now runs on every pull request into main (`.github/workflows/pages-build-check.yml`).

- **Sept 25 2026: a "Pages build" check now runs on every pull request into main (`.github/workflows/pages-build-check.yml`).** The Pages deploy only runs after a push to main and the design system audit does not build the site, so two static-export errors (a dynamic route with no `generateStaticParams`, a `useSearchParams` caller outside Suspense) reached main and failed only after the merge. The new workflow runs the same build as the deploy (Node 20, `next build` with `PAGES_BASE_PATH=/<repo>`) without deploying, cancels superseded runs on the same branch, and its job is named "Pages build" so it can be made a required check. **Making it required needs a branch rule on main (repo admin); the workflow alone reports a red check but does not block a merge.**
