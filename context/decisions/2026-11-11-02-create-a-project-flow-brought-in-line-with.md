# 2026-11-11 - Create a project flow brought in line with the design system (consistency audit)

- **Nov 11 2026: the audit and its fixes.** The designer asked for every inconsistency against design system components in the Create a project flow, then a table by severity with screenshots (`audit/create-project-consistency-2026-11-11.md`, 21 findings: 5 high, 10 medium, 6 low), then: "let's fix all." Principles: 3 One system (the same job has the same pattern), 1 Say less, 5 Make it obvious. Closest pages borrowed from: the form's own first sections (`FormRow`), the record pages (`RecordRow`), the lists (`Table`, `TableCard`), `ListEmptyState`, `RestrictedState`.
  **Fixed (17).** (1) The species panel's bespoke choice tiles are a `RadioGroup` (4.1 item 7). (15) The five restriction sections (Embargo, Species, Cultural, Locations, All records) are laid out in `FormRow`s like the other five: `RestrictionTypeFields` takes an opt-in `row` renderer, so the project page's cards, which do not pass it, are unchanged; `ExpectationSelect` and `JustificationField` take an opt-in `hideLabel`.
