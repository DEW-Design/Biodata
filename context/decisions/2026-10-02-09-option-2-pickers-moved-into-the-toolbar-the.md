# 2026-10-02 - Option 2 pickers moved into the toolbar; the on-dark Select pill is withdrawn

- **Oct 2 2026: Option 2 pickers moved into the toolbar; the on-dark Select pill is withdrawn.** The designer rejected the quiet pills on the card: "against the design system". They were right. The `onDark` look (a translucent white fill, a white ring, white text at 70%) was invented, with no Figma source, hard-coded opacities and no place in the design system, and it was added to a base component (`Select`) to serve one screen (2.5, 2.1, 1.5). The designer had picked it from the options offered, but a component style is not the screen's to introduce.
  - **Withdrawn:** `components/base/select/select.tsx` and the Select doc page are restored exactly (the `onDark` prop, its styles and its API row are gone); the `heroControls` slot on `DataReport` is removed with it.
  - **Option 2 is now what the design system already does:** the report's own small `Select`s in the toolbar, right after the search and before Filter, where a report's project scope lives on Species Detail and Events (4.6 item 4). The card keeps only the title, the description and the facts. Project is a `sm` Select 14rem wide; Dataset is 10rem and shows the dataset ID alone, because with the file name beside it the ID was pushed out of the field; each list opens at least 24rem wide, so the file names read in full beside their IDs (the existing `popoverClassName`). Option 1 is unchanged.
  - **Verified:** `tsc`, `eslint`, `check:contracts`; live: at 1440 and 1708 the toolbar is one line (search, Project, Dataset, Filter, Columns); at 1280 Filter and Columns wrap to a second line; picking a project moves the dataset and the facts, Escape keeps the value and returns focus; zero console errors.
  - **Lesson recorded:** do not offer or build a restyle of a base component as one of several layout options; a new look for a component is the designer's call through the component workflow (1.4), not a prop added while exploring a screen.
  - **Open:** which option stays; the toolbar wraps below about 1300px wide (the same as the other report toolbars). Not committed.
