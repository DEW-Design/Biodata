# 2026-09-30 - Project page typography pass: one hero, readable small text, one font

- **Sept 30 2026: typography on the project page template (Option 1) fixed, per the designer ("typography in option one is an absolute mess"), with `/emil-typography` and `/emil-design-foundations` run as CONTRACTS 2.9 and 0.6 item 8 require.** Sources, in the order 2.9 sets: (1) the design system's scale and weights (`/primitives/typography`: display xs 24/32 semibold, text xl-xs 20/18/16/14/12px, weights 400-600) and its components' own text; (2) the sibling patterns already in the app (measured live: `RecordHero`, `HeroMeta`, `RecordRow`, the DLA record page's eyebrows, the project list's meta text); (3) the two Emil skills' rules (measure near 65ch, real contrast floors of 4.5:1, nothing under 12px, one typeface, hierarchy by making the important thing prominent).
  - **Method:** every text run in main and the header, on the four tabs plus the open record inspector, measured with `getComputedStyle` (size, weight, line height, tracking, case, colour, family) at 1708x1024 for BioData Admin. Before: 30, 34, 22 and 21 distinct full styles per tab (size, weight, leading, tracking, case, colour, family). The 10 size/weight pairs on the Project tab came down to 9. Then the same sweep for sub-12px text, non-Barlow text, contrast of meaningful small text, and wrapped copy without balance.
  - **What was wrong and what changed:**
    - **The hero was hand-rolled and disagreed with every other record page.** Title 24px medium (500) with no balanced wrapping, where `RecordHero` sets 24px semibold with `text-balance` (the design system's display xs is semibold). The page now renders the shared `RecordHero`, `HeroMeta` and `RecordBackLink`, so the eyebrow, title, facts and back link match by construction. Page rhythm now follows the record pages (back link, hero, tabs each carry `px-6`).
    - **The count in each metric tile was as faint as its label** (tertiary, 18px medium, same colour as the 14px label above it), so the number, which is the content, did not lead. It is now primary (`MetricTile`, shared with Explore, so Explore's tiles follow; the Species group tiles and "Survey at a glance" too).
    - **Meaningful small text was set in `text-quaternary`** (gray-500, about 3.4:1 on white), below the 4.5:1 floor: tree type labels and IDs, the species family line, the inspector's record type, attachment sizes, counts, method lines, review-screen meta. 29 such places on the project page's files, and three in the shared artefact card (`artefact-lightbox.tsx`), now `text-tertiary` (5.3:1), the same colour the project list uses for its 12px descriptions. **Left alone on purpose:** the uppercase 12px eyebrows and table heads (`text-quaternary`), because the DLA record pages and the design system's table head set that role in the same grey (sibling wins, 2.9), and the empty-state phrases ("Not provided"), which are deliberately faint (2.3). Both are recorded below as open questions.
    - **The Cards / Table and Tree / Table switch had a 3.2:1 inactive label** (page-local `segmentClass`): now tertiary.
    - **Flag, comment and attachment counts took the icon colour for their number** (flag orange at 3.2:1, the others 3.4:1). The tone now colours the icon only; the flag count is `warning-700` (5.0:1) and the others tertiary.
    - **A hand-rolled 10px "Primary" pill on contacts** is now the design system `Badge` (12px). Two 11px chips in the landscape scores are now `text-xs` (12px).
    - **The organisation name in "Published by" was 14px medium in secondary** where the contacts' names beside it are primary: now primary.
    - **Long values ran to about 105 characters a line** (the abstract). The value column is capped at 65ch (`max-w-prose`): 514px, 5 lines, about 78 characters a line on average.
    - **A second typeface on the map:** Leaflet's scale bar and attribution were set in Helvetica Neue with its stock blue and grey. One rule in `globals.css` (prefixed `body` to beat `leaflet.css`, which loads after) gives every map the surrounding Barlow and the text tokens.
  - **Result, re-measured:** hero title 24px/600 balanced on all five projects, the canonical route, a record page and the DLA page; no non-Barlow text; no text under 12px except the header's "DEW" pill; no multi-line copy without balance or pretty wrapping; the remaining sub-4.5:1 hits are false positives of the measurement (white text on the gradient hero, Leaflet's translucent white credits panel) or design-system components (the avatar initials).
  - **Verified:** `tsc`, `eslint --max-warnings=0` on every touched file, `npm run check:contracts` and a production `next build` pass. Live sweep, zero console errors: five projects across four roles, the canonical `/pages/project-detail`, a record page, the review screen, Explore option 2 and the DLA page.

    2. **The faint grey (gray-500) is the app-wide colour of the small uppercase eyebrows, the table heads and the inactive tab labels**, all around 3.2 to 3.4:1 on white, and the "Not provided" empty value. They are the design system's own; darkening them is a token-level decision (one change in `app/globals.css`, not per page).
    3. **Sentence case vs uppercase:** the design system's Badge is uppercase by design (12px, semibold, tracked); the hero pill "ACTIVE" and the tab counts follow it.
    4. **The abstract now takes 5 lines** (was 3) in a 65ch column; the row is 514px wide inside a wider card. If the card should hold wider lines for the sake of the layout, the cap can be raised to about 75 characters.
