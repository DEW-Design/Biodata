# 2026-09-30 - Dropdown menus sit 12px from their trigger

- **Sept 30 2026: the project hero's "..." menu sat too close to its button, per the designer's screenshot.** The cause was in the shared component: `Dropdown.DotsButton` draws a 2px outline 2px out (a 4px reach) while it is pressed or focused, which includes the whole time its menu is open, and `Dropdown.Popover` used react-aria's default 8px offset, leaving 4px between the ring and the menu.
  - **Changed:** `DropdownPopover` (`components/base/dropdown/dropdown.tsx`) now defaults to `offset={12}` (4px of ring plus the same 8px gap as before). A caller can still pass its own `offset`; none of the app's `Dropdown.Popover` uses did. Fixed once in the component so every "..." menu and dropdown gets it (1.9, 1.3): the project hero, record action bar, Home cards, Explore area layers, table row actions, the breadcrumb project switcher and the Add menu style dropdowns.
  - **Verified:** measured live, the hero menu is 12px from the button box (about 8px from its ring) and the breadcrumb switcher 11.8px, up from 8. `tsc`, `eslint --max-warnings=0` on the file and `npm run check:contracts` pass; zero console errors. Not measured: the record action bar, Home card, Explore area layer and table row menus (no reachable instance was clicked in this pass); they share the same popover and trigger, so they change by the same 4px.
