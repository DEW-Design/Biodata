# 2026-10-23 - Area chip labels at the size of the Search results heading

- **Oct 23 2026: Area chip labels at the size of the Search results heading.** The designer, with a crop of "SEARCH RESULTS 54" above a chip ("CIRCLE 1 x"): "use the font size of search results in 'circle 1'" (refined with `/refine-prompt`: the type scale, the Tag, size only; the table and prompt were shown with the reply).
  - **The fault:** the chip's label was 14px and the heading that names it 12px, so on a card where the heading says what the chips are, the chips outweighed it (Principle 2). Weight (600), case (uppercase) and tracking (wide, 0.3px) were already the same.
  - **The change:** the area chips' label is **12px**, the heading's size (measured: heading and chip both 12px/600, uppercase, 0.3px tracking; the colours stay as they were, the heading quaternary and the chip secondary, since only the size was asked). The chip keeps the design system's large Tag box (28px high, the larger Tag the designer had asked for) with the smaller type inside it; the icon follows the type (14px, it was 16px) and the close X stays 14px.
  - **How, without restyling the Tag at the call site (2.9):** `TagGroup` has a new opt-in `textSize="xs"`, passed down to its tags, which sets `text-xs` whatever the group's size is and sizes the icon to match. Default unchanged: the table filter chips (medium, 14px) measured the same after (14px/600, 136 by 20px), and a small Tag's icon is still 12px.
  - **Checked live (Playwright, Super Admin; zero console errors):** a drawn circle and an entered point as chips under the heading, 106 by 28px each, looked at in a 3x screenshot. `npx tsc --noEmit`, `npx eslint` on the touched files and `npm run check:contracts` clean.
  - **A note on the combination:** a 28px chip with 12px type is mostly padding and an icon; if it feels loose, the medium Tag (20px high) with its own 14px type was the other way to bring the chip down, and the small one (12px type, 20px high) is the exact match to the heading. Say which, if this is not it.
