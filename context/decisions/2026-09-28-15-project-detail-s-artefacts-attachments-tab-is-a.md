- **Sept 28 2026: project-detail's Artefacts & Attachments tab is a table, per page feedback (a screenshot of Explore's Artefacts table: "artefacts and attachments should be a table... don't have the hierarchy column").** The horizontal tile carousel is replaced by a new page-shared `ArtefactTable` (`app/pages/_shared/artefact-table.tsx`): a heading with a real `CountBadge`, a search field (name, record, creator), a Filter button with a Type section (only the types present), sortable columns (Attached resource, Type, Attached to, Creator, Created; default newest first) plus Size, and numbered pagination. No Hierarchy column. A row (click, or Enter on the focused row) opens the existing artefact viewer at that artefact. Columns are the fields this project's artefacts actually carry; Explore's "Attached to Concept" and "Record ID" are not in this data, so "Attached to" shows the record label as before. It is an embedded table in a detail tab, but it carries `bodyScrollable` and a sticky header anyway, so no change to the 4.2b allow-list was needed. `ArtefactCarousel` now has no product caller (left in `artefact-lightbox.tsx`).
