# 2026-09-30 - Survey at a glance redesigned as one summary card; flagged concepts replaces questionable records; public users see everything

- **Sept 30 2026: Survey at a glance redesigned as one summary card; flagged concepts replaces questionable records; public users see everything.** Per designer feedback on the four-box version ("I don't really like how this looks... flagged concepts and questionable records are the same... No limit what public user can see").
  - **One summary card, four cells** (`SurveySummary` in `project-tab.tsx`), the metric-strip pattern of Stripe's dashboard and Vercel's project overview. Mobbin was not reachable this session (no connector or login), so the patterns were taken from those products, named here. Each cell: a label, one figure, one line of context, and the whole cell opens its page (a chevron shows on hover). Survey records carries a composition bar (events, occurrences, observations in brand 700, 500, 300) and a legend whose items open that kind. Flagged concepts: the open count, a "Needs review" badge, "Across N records, oldest waiting N days". Datasets: the count, the latest upload's date and workflow status, and Upload. Artefacts and attachments: the count and its split by file kind. Laid out by the content column's width (container query): stacked, 2 x 2 from 520px, one row from 1040px.
  - **Type sources:** figure from Home's `KpiStat` (text-2xl medium, tabular figures, measured live: Barlow 24px 500, `tabular-nums`); context line from `KpiStat`'s note (text-sm tertiary); cell label from the project-tab card heading (text-sm semibold primary).
  - **"Questionable records" is gone: it is flagged concepts.** The figure counts open flagged concepts (7), not records (6); records go in the context line. The cell opens the flagged concepts management page (`?view=review`) for BioData Admin and Privileged Admin; other roles cannot open that page, so for them it opens Survey records filtered to "Has flagged concepts".
  - **Public users see everything**, including the Datasets page. Upload is visible to them everywhere and opens the sign-up prompt, as the project card's Upload dataset already did. That behaviour moved into one shared `UploadDatasetButton` (`app/pages/_shared/upload-dataset-button.tsx`), now used by the project card, the Datasets cell and the Datasets page.
  - Verified: `tsc`, `eslint --max-warnings=0` on touched files, `npm run check:contracts` clean. Live Playwright at 1600 (BioData Admin, Registered User, Public User), 2400 and 700: the layout at each width, Flagged concepts opening review for the admin and the filtered records for the others, Upload opening the upload page or, for a public user, the sign-up prompt; zero console errors. `/emil-typography` and `/emil-design-foundations` not available this session.
  - **Found, not fixed (outside this change):** Home's `KpiStat` label uses `text-md`, which `app/globals.css` does not define (a dead class, CONTRACTS 2.1), so that label falls back to the inherited size; `check:contracts` did not catch it.
  - **Open:** whether non-admin roles should see the Flagged concepts cell at all, given they cannot manage them. Not committed.
