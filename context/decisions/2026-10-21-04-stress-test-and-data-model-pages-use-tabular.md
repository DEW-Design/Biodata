# 2026-10-21 - Stress test and data model pages use tabular figures

- **Oct 21 2026: Stress test and data model pages use tabular figures.** Designer: "tabular-nums for numbers, please. No dancing layouts." Lab and config page only.
  - **Changed.** `tabular-nums` (the Tailwind utility the labs already use, `font-variant-numeric: tabular-nums`) is set once on the root of `/proto/data-model-stress-test` and of `/config/data-model`. The property inherits, so every figure on both pages has one width per digit: the file bar's counts and badges, the tab and filter labels, the Records and Summary tables, the tree, the field counts and codes. A new number added later is covered without a second edit. The JSON panel is monospace already and is unaffected.
  - **Why it matters, measured.** Barlow has the figures: at 40px, "1111" and "0000" are both 84.33px wide with the feature on, and 56.38px and 90.41px without it, a 34px swing at that size for the same number of digits.
  - **Verified (ran, in Chromium, no console errors).** Computed `font-variant-numeric` is `tabular-nums` on the file bar counts, the "N with errors" text, the record count badge, the top tab labels, the tree rows, the filter tabs "With errors (n)", the Records table cells and error badges, the Summary "Rows" cells, and the config page's "N fields" labels. Layout, on the 12,072-record workbook: none of the three top tabs or three filter tabs moved or resized when another was selected; the file bar and the table header held their position and size across three "Load 100 more" clicks; the "Load 100 more (N not shown)" button stayed 258.7px wide as N fell 11,672, 11,572, 11,472, 11,372.
  - **Not done.** Other labs and pages are untouched. The Emil typography and foundations skills (§0.6 item 8) were not run; the change is one inherited property, measured as above. Not committed.
