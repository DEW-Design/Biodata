# 2026-10-01 - Text editor (Tiptap) ingested: dependencies linked, dead classes and hex colours replaced, doc page added

- **Oct 1 2026: Text editor (Tiptap) ingested: dependencies linked, dead classes and hex colours replaced, doc page added.** The designer ingested Untitled UI's Text editor into `components/base/text-editor/` (6 files) and asked for its dependencies to be checked and the ingest flow followed.
  - **Dependencies:** all eight `@tiptap/*` packages are in `package.json` and `node_modules` and resolve; `@untitledui/icons` moved 0.0.22 to 0.0.23 with the CLI run (every icon import still type-checks). Imports into `input`, `select`, `tooltip` and `cx` resolve to the real exports.
  - **Override and inventory:** OVR-005 to OVR-010 in `contracts/overrides.json` (one per file, reviewBy 2027-03-25, same shape as the progress-steps ingest). The six files were added to `contracts/component-inventory.json` by hand, not with `--update-baseline`, so no other baseline moved (the working tree holds other sessions' changes).
  - **Dead classes replaced (verified against the compiled CSS):** `text-md` (now `text-sm`, the TextArea size), `bg-border-primary` (now `bg-[var(--ui-border-primary)]`), `dark-mode` (DEW has no dark theme; the bubble menu's `theme` prop did nothing and is removed), `pressed:` and `in-pressed:` (the react-aria Tailwind plugin is not loaded here; the pressed state now comes from render props).
  - **Hex colours removed:** the 16 text-colour swatches, the custom-colour default and the resize-handle strokes were hard-coded Untitled UI hex values. Swatches now name DEW tokens (Gray 900 to 300, White, Success 600, Accent 600, Brand 600 and 800, Warning 600 and 800, Error 600 and 800) and the hex is read from the token when the picker opens (`getTokenColor`), so the stored colour is the DEW value. Read through the utility class because the stylesheet only emits a theme variable when something uses it (`--color-warning-800` is not emitted).
  - **Behaviour fixes found in the live pass:** the editor rendered in Geist (doc chrome leaking in, no `font-barlow` on the root), now Barlow; a disabled editor was still editable (`editable` is read only at creation), now `setEditable`; the character counter never updated on typing, now subscribed with `useEditorState`; Cmd+K fired from anywhere on the page, now only while the editor has focus and with `preventDefault`; the image picker accepted any file, now `image/*`; the colour picker and its radio group had no accessible names, now named; the advanced toolbar overflowed narrow containers, now wraps.
  - **Honest affordances (2.10):** the font family default said Inter (not loaded), now Barlow; the size default said 16px while the text is 14px, now 14px; the unused right and justify buttons advertised Cmd+R and Cmd+J that nothing wires, labels corrected; the Generate button did nothing and is now opt-in through `onGenerate`.
  - **Docs:** `/components/text-editor` (Playground, Toolbar types, Bubble menu, Character limit, Disabled, Invalid, API, Usage, Figma "not linked yet"), config key `text-editor`, slotted A-Z in `lib/nav.ts` and the README table.
  - **Verified:** `tsc`, `eslint` on the touched files and `check:contracts` clean; a live browser pass (zero console errors) over the doc page: Barlow 14px, Bold by keyboard, colour picker by mouse with Escape returning focus and keeping the colour, invalid, disabled, limit, bubble menu, Cmd+K scope, tab order.
