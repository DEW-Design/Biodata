# 2026-10-01 - Report counts move into the card and export into its menu

- **Oct 1 2026: on the designer's annotated screenshot of the Species Detail Report ("All these can just go here", "these are an overview", "three dot menu - keep consistent with other screens", "left: search, right all projects, then the filter button"). Follows 2026-10-01-18.**
  - **Totals are facts in the card.** The Events, Occurrences and Observations tiles are now facts in the gradient card beside Scope and Columns. The same is applied to the other reports that had the same tiles, for consistency (the designer asked for one pattern): Project Detail (Datasets, Events, Occurrences, Observations, counted for the projects in view, so they follow search and filters), Events, Occurrences and Observations (the same four, for the chosen project, on every tab) and Data Validation Error (Total records, Clean records, Records with errors, plus Ingested). Where a total already says the row count, the Rows fact is left out (`showRows={false}`: Species Detail and Events, Occurrences and Observations, whose rows are those records, and Data Validation Error, whose rows are the errors), so a number is not shown twice. `DataReport`'s `facts` takes a list or a function of the rows in view.
  - **Overview tiles stay** where they break a total down: the five species groups on Species Detail and, on Data Validation Error, the three kinds of error (business rule failures, coordinate mismatch, metadata mismatch), as `MetricTile`s under the card. Project Detail and Events, Occurrences and Observations have no tile rows now. This gives the table more height: Species Detail's table starts 74px higher than before this round (about seven rows visible at 1440x900, up from five).
  - **Export and the other actions are in the card's "..." menu.** A report has no next step, so there is no white button (CONTRACTS 4.6 item 2: one button for the next step, every other action in the menu). Export CSV on Project Detail, Species Detail and Events, Occurrences and Observations (still the rows in view, all columns; checked: 23 rows in the file, 23 in the table). Data Validation Error's menu holds Download error report, and Download source dataset and Map visualise (disabled: uploaded files are never read).
  - **Toolbar order:** search, then the project scope Select (Species Detail and Events, Occurrences and Observations), then Add filter. `DataReport`'s `toolbarStart` is now `scopeControl`, placed after the search.
  - **Contract:** CONTRACTS 4.6 item 4 says all of this (facts, overview tiles, the menu, the scope's place).
  - **Verified:** `tsc`, `eslint --max-warnings=0` on the reports folder, `npm run check:contracts`. Live with Playwright at 1440x900, zero console errors: the facts, the menu contents and the export on all four changed reports, the toolbar order.
