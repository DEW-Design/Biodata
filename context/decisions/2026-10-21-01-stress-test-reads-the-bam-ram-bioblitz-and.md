# 2026-10-21 - Stress test reads the BAM, RAM, Bioblitz and Ramble templates: returns, matrices, locked and derived sheets

- **Oct 21 2026: Stress test reads the BAM, RAM, Bioblitz and Ramble templates: returns, matrices, locked and derived sheets.** Designer sent four workbooks, "different collection methodologies": BAM Site 42 (Bushland Assessment), RAM-VA1 (Rangeland Assessment), a Bioblitz macroinvertebrate workbook and an example Ramble (.xlsm). "Understand their templates, and sample data to ascertain how uploads / tree structure formation would happen ... There are a few locked sheets on certain templates - this is basically admin stuff that gets rolled up based on data entered by users. Let's now see if these hold up in the stress test." Lab and config only.
  - **What each template is.**
    - **Ramble (.xlsm):** a form (RAMBLE, FAUNA) the user fills in, beside BDBSA's own SITE, VISIT, SPECIES tabs for it. Same as the Heathfield file. It was being read as CSV text, because the file extension was .xlsm; that was the whole of its failure.
    - **BAM and RAM-VA1:** a scoresheet. Locked sheets (Block, Site - Flora Sp., Site - Fauna Sp., Site - Scores, the offset summaries; in RAM, Perennial Sp. and Threatened Sp.) score the block. The records end in a flat BDBSA return: a formula-driven "BDBSA Flora" and "BDBSA Fauna" tab, and a finished "EK-flora" / "EK_flora" tab (values, with coordinates and survey number). The return has no Site and no Visit.
    - **Bioblitz:** a matrix (one column per sample, one row per taxon, an abundance in each cell) and "Input Data Formatted", BDBSA's flat return of the same records (170 taxa by 15 samples is 440 cells, and 440 flat rows).
  - **Added.** `methodology-ingest.ts` (new, pure): the flat return reader, which makes a Site (a survey and a place: coordinates, or the location comment when there are none) and a Visit (a Site on a date) from the rows; and the matrix un-pivot (a Site is a river and a site name, or the river and the sample point code when there is none; a Visit is a Site on a sample date; one species row per filled cell). Both give the 3-tier rows the Ramble form gives, so the pipeline, the tree and the download are the existing ones. `workbook-ingest.ts`: .xlsm, .xlsb, .xltx, .xltm open as workbooks; sheet protection and formula share are read from the workbook XML (SheetJS does not surface the first, and undercounts the second because it keeps a shared formula only on its first cell); dates come out as ISO, not as the US-ordered text SheetJS writes; formula errors (#N/A) read as blank; the explanation row under a header is skipped; a header ending "Comments" is recognised.
  - **Locked and derived sheets (decision to confirm).** A protected sheet is left out when the file has other sheets to read, and the report says "Locked sheet: the template's layout and roll-ups, not entered records". Checked at cell level: protection is on the entry sheets too (BAM's Flora Sp. has 113 unlocked input cells, Block 12), so the lock alone does not mean admin-only; they are left out because the species they hold is also in the finished return (BAM: 31 NSX codes in the entry sheet, 31 in EK-flora, 31 in the formula tab; RAM: 6, 6, 6). A return tab that is at least 80% formulas is "calculated by the template" and is left out when the file has a finished return. A file with a form or a matrix reads that, and its BDBSA tabs for the same records are left out as before. Also: a tab name that holds both "Site" and "Flora" (the BAM entry sheet) no longer reads as a Site.
  - **Survey number.** Not on a form or a matrix (BDBSA assigns it on receipt). When BDBSA's own tab in the same file carries one, and only one, the Project takes it and the report says so: Heathfield and the example Ramble 653, Bioblitz 1088. BAM (823) and RAM (1334) carry it in the return itself.
  - **Model.** An abundance range ("2 - 10", "11 - 100", "101 - 1000") classifies as a Population (`classifySpeciesRow`), unless the range tops out at one. The matrix names no species type; every taxon is read as an invertebrate because it is the macroinvertebrate matrix, stated in the report. A taxon's family, order, EPA taxa code, life stage and habitat stay on the Occurrence, as fields with no template home, flagged for review.
  - **Result (ran, in Chromium, no console errors).** BAM Site 42: Project 823, 1 Site, 1 Visit, 31 plants, 64 records, 0 errors. RAM-VA1: Project 1334, 1 Site, 1 Visit, 6 plants, 14 records, 0 errors. Bioblitz: Project 1088, 12 Sites, 12 Visits, 440 invertebrate records, 904 records, 0 errors. Example Ramble: 534 records, 8 errors, the same 8 plant rows as Heathfield (dominant storey, planted or released, on a Community observation). Heathfield, the sample data (10 valid, 8 errors), the sample workbook, the BDBSA-style CSVs and the 12,072-record workbook (0.67 s) are unchanged. The downloaded 3-tier workbook of BAM re-uploads to the same 64 records.
  - **Findings about the files, added to the known gaps.** (1) The Bioblitz matrix and BDBSA's flat tab agree on every taxon and abundance, except that 28 records the matrix calls habitat Edge are Pool in BDBSA's tab (the 25 Riffle records agree), and BDBSA's tab has one extra Nematoda row with no abundance. (2) RAM-VA1's formula-driven "BDBSA Flora" tab puts latitude and longitude in the Easting and Northing columns and leaves the survey number blank; the finished EK_flora tab is correct. (3) A return has no Site or Visit, so they are inferred. (4) The scoring (condition scores, weed cover and threat, regeneration, palatability, utilisation tallies, offsets) has no home in the model.
  - **Verified (ran).** `tsc`, `eslint` on the touched folders and the config page, `check:contracts`: clean. Not run: a keyboard pass, the typography skills (§0.6 item 8; the report reuses the existing table and badge), and a second real Bioblitz or scoresheet file: the three here are single examples, so a template that differs (a scoresheet with several sites in one workbook, as RAM's "SiteCode" column suggests) is untested.
  - **Open.** (1) Is dropping locked sheets right when a template has no finished return to fall back on? Today such a file would read as "None of these tabs could be read". (2) BAM and RAM carry several sites in one block; their return has one site's coordinates. Confirm how a block with several sites arrives. (3) Should the scoring be modelled, or stay with the scoresheet? (4) Bioblitz: is a Visit a site on a day, or one per sample (a pool and a riffle at one site on one day are two samples)? (5) Whether BDBSA wants the habitat discrepancy, the missing abundance and the RAM formula tab reported to them. Not committed.
