# 2026-10-01 - Prototype tools bar kept inside the window

- **Oct 1 2026: Prototype tools bar kept inside the window.** The designer: "The floating persona switcher is getting disappered. Fix it."
  - **Cause:** the bar's position is an offset from the right and bottom edges, saved in localStorage when it is dragged (`app/_prototype-tools/use-drag-position.ts`). It was clamped to the window only while being dragged; on load, on a window resize and when a screen added tools it was used as saved. The designer's saved offset was 502px from the right. Notification Management adds two tools (Layout, Sample size), widening the bar to 756px, so in a 1280px window its left edge sat at 21px, and any narrower window, larger zoom or shorter screen pushed it partly or wholly off screen, role switcher included.
  - **Fix:** `useDragPosition` now measures the bar (a ResizeObserver on the element, and the window's resize event) and clamps the offset on every render so the whole bar stays at least 8px inside the window; when it is wider than the window the right edge wins, since the role sits there. The saved offset is left unchanged, so a wider window puts the bar back where it was put. The bar also gets `max-width: calc(100vw - 16px)`. The status bar attaches the hook's element callback by destructuring it (`attach`), which the React compiler lint accepts where `drag.ref` was read as a ref.
  - **Sibling:** `app/proto/tools/variants.tsx` uses its own copy of the hook (`app/proto/tools/use-drag-position.ts`); labs never ship (5.4), so it is unchanged.
  - **Verified:** `tsc`, `eslint` on `app/_prototype-tools`, `check:contracts` clean. Live: at 1280x577 the bar with three tools sits inside the window; with a saved offset of 2000px right and bottom (off screen before), it is pinned fully on screen at the top left and the saved value is unchanged; the designer's own saved position was restored afterwards. Zero console errors. Not committed.
  - **Note:** the bar can also be folded by its X into a small "Prototype tools" tab, remembered across screens; that is by design, not this bug.
