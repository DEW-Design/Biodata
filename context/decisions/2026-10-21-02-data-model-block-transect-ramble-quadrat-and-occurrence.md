# 2026-10-21 - Data model: Block, Transect, Ramble, Quadrat and Occurrence get field lists from the record-page frames

- **Oct 21 2026: Data model: Block, Transect, Ramble, Quadrat and Occurrence get field lists from the record-page frames.** Designer sent six screenshots of the record-page frames, one per type: Occurrence Population, Occurrence Individual, Ramble, Block, Quadrat, Transect. These were the types the data model page listed as "no schema yet". Lab and config only.
  - **Added to `FIELD_SCHEMA`** (`config/data-model-schema.ts`), in each frame's own section order and under its exact labels. Transect, Quadrat and Block, 22 fields each: Name, Description, Source ID, Comment (named for the type: "Transect Name", "Quadrat Comment"); Start Date, End Date, Duration, Date Accuracy; Observer 1 to 3; Location Details, IBRA Region, IBRA Sub Region, Location Method, Datum, Reliability, Sample Site Dimensions, Location Comment; Photopoint Marker Present, Disc Number, Direction. Ramble, 27: the same, with the frame's coordinate table (Zone, Easting, Northing, Latitude, Longitude) under Location Details. Occurrence Population, 23: Legacy Sighting #, Species Seq No, Occurrence Name, Description, Taxonomic Type, "NSX Code & Species" (one field, as drawn), Occurrence Status, Occurrence Comment; the temporal, observer and location blocks; no Photopoint. Occurrence Individual, 34: the Population list plus the Voucher section (Voucher Type, Voucher Series, Voucher Number, Voucher Images, Institution Name, Institution Rego #, Determination Date, Determination Date Accuracy, Determiner 1, Determiner 2, Transfer Date). The shared sections are built once and reused, so a change to "Observers" is one edit.
  - **Block is a valid Event type** (`VALID_TYPES_BY_KIND`, first in the list). It is the one type the sandbox did not know. Nothing yet creates one: the tree still starts at Site.
  - **Not fields.** Each record's own ID, Attached Resources, Nested Records (structural or calculated, as for Site and Visit), Custom Property (any column the schema does not know, flagged for review, as before) and Block's typed Comments (a repeating list).
  - **The pipeline follows the frames.** A species row's Occurrence now carries "NSX Code & Species" ("C01541 - Acacia baileyana", the separator is ours, the frame shows no example) and its Taxonomic Type; the Observation under it no longer carries either. The frames have no count on an Occurrence, so Number Observed stays only on a Population Observation; an Individual or a Community Observation does not repeat it (the type already says one animal, or present but not counted). Voucher and registration columns take the frames' names (Voucher Number, Institution Rego #). An Occurrence's coordinate and visit-date columns are consumed (they only trace it to its Visit, the frame has no field for them); its name, common name, family, habitat and the like are kept and flagged, never reported as another record type's field. The sample data's Transect, Ramble, Quadrat and Occurrence rows now show their field lists.
  - **Page.** `/config/data-model` lists every type with its field count (none say "no schema yet"); the BDBSA column reads "Not yet checked" for the six new types, since no export has been checked for them, and the intro says so. The Excel template has a sheet for each of the 12 types (it had 6).
  - **Verified (ran).** `tsc`, `eslint` on the touched folders, `check:contracts`: clean. Live in Chromium, no console errors: a CSV with a Block, Site, Visit, Transect, Quadrat, Ramble, both Occurrence types and an Observation is 9 valid, 0 errors, and only the two populated unknown columns are flagged (it was 25 flagged lines on the same data before, mostly blank). Unchanged: Heathfield (526 valid, 8 errors), the example Ramble (same), BAM (64, 0), RAM-VA1 (14, 0), Bioblitz (904, 0), the sample data (10 valid, 8 errors), the sample workbook (17, 2), the CSV trio, the 12,072-record workbook (0.68 s). The BAM Occurrence card shows "NSX Code & Species: C20005 - Acacia victoriae ssp." Not run: a keyboard pass, the typography skills.
