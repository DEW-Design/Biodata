- **Sept 28 2026: `/proto/dataset-ingestion`, a lab for where a dataset's ingestion progress lives on the project page, per direct request ("data ingestion will take some time: go through the data model, map it against the structure, then spit out the tree... can the progress sit on the project view? ... sense check and proto this").** Ingestion is treated as three stages (check the data against the model, map the rows to the project's structure, build the records tree), each with real numbers ("48 of 78 rows placed"), and the run as the payoff the person came for: the new site, visits and occurrences appear in the project's records tree marked "New". One run is simulated over 30 seconds (`ingestion-sim.ts`, progress derived from elapsed time so it survives re-renders and speed changes; 1x, 5x, 20x), with or without 12 rows that cannot be placed. Three options on one axis (how loud and how close to the data), compared with the floating options control, with a second "Lab controls" button to start, restart, restart with problems, reset and change speed: **A**, a notice under the identity card, built on the real `TaskItem` (CONTRACTS 4.6 allows one notice saying where the record stands); **B**, a compact card at the top of the records tree (column 2) beside the new records filling in; **C**, one chip in the card's actions ("Adding data - 62%") opening a popover with the stages (`Progress.IconsWithText`) and the files. Built only from real components; the lab is exempt from the shell contract but uses the real header, rail and identity card. Added to the `/proto` index.
  - **Verified:** `tsc`, `eslint --max-warnings=0`, `npm run check:contracts` clean; live Playwright pass (installed and removed, `package.json` unchanged) on all three options at 1600x1000 as registered user: mid-run states, the tree gaining Site SU00511 with three visits and "N occurrences" rows marked New, the done state, and the problems case (chip reads "Needs attention", stage two shows "66 of 78 rows placed" in the error state, the last visit is short by 12); zero console errors.
