Follows `2026-10-15-05-*` and `-06-*`; the report stays BioData Admin and Super Admin only.

  **The tab.** "Taxonomy list - Aus / World" (`?tab=aus-world`, icon `Globe01`, the one Taxonomy Management's own Australian and Overseas Distribution tab uses), built as the other two: `taxonomy-aus-world-tab.tsx` (its report props and parameter fields) and `taxonomy-aus-world-data.ts` (its parameters and how they narrow the rows). The parameters are fields above the table in the sheet's order: Species code & name, NSX code and Common name (typed, matching part of the value; Common name also reads every common name the taxon has), State/OS area (chosen from the areas the rows hold) and Start date and End date (the design system's date field with a calendar, both empty). They narrow the rows and the hero's counts (Taxa and Areas), and are written above the columns of Export CSV and Export XLSX under the title "BioData - Taxonomy list - Aus / World". A row is one State or overseas area recorded on one taxon, read from its Australian and Overseas Distribution table (`tables.ausDistribution`, Flora: the State / OS field and the same columns as SA Regions; Fauna: its Australian Distribution, a region and a comment). A taxon with no area has no row.

  **One row builder and one column set for the two area sheets.** The SA Regions and Aus / World sheets have the same 25 columns and differ in the area column and in the last four labels, so the row (`DistributionRow`, formerly `SaRegionRow`) and its builder (`distributionRowsFor(taxa, source)`, with `SA_REGIONS_SOURCE` and `AUS_WORLD_SOURCE`) are in `taxonomy-sa-regions-data.ts`, and the columns are `distributionColumns(labels)` in `taxonomy-distribution-columns.tsx`, which both tabs call. The SA Regions tab's output is unchanged: checked, 5 rows, 25 columns, the same parameters. The row gained the taxon's common names for the Common name parameter.

  **The sheet's last four labels do not agree.** "SA Created By", "SA Creation Date", "SA Edited By", then "Reg Edit Date". They are kept as the sheet has them, in sentence case ("SA created by", "SA creation date", "SA edited by", "Reg edit date"), and the question is below. Everything else is labelled as in the SA Regions tab (sentence case, "Estab" spelled out, "Conservation status" for "Cons Stat.", "Collection < 50 yrs" for "Colln < 50yrs", "Reg" kept). The Date parameter reads the record's own days (its creation and edit dates); the Filter menu offers the Yes or No columns and who created or edited the record, none of which the parameters cover.

  **Sample data, shared with Taxonomy Management.** As for SA Regions, the seed Flora taxa held no Australian and Overseas Distribution rows. `tx-data.ts` now gives the two placeholder taxa rows (`SAMPLE_STATES`: Eucalyptus leucoxylon in SA, Vic and NSW; Xanthorrhoea semiplana in SA and Vic), the same placeholder shape as the regions (Yes for native, established, ID certain and Dsn certain, placeholder people and dates, nothing invented in the Herbarium, voucher, census, BS or conservation fields).
