# 2026-10-01 - Areas rows on one line and the banner pattern documented

- **Oct 1 2026: Areas rows on one line and the banner pattern documented.** Page feedback on Explore, two items. (1) The designer likes how the data-access banner shows up and asked for the pattern to be documented. It was a recipe repeated at one call site (`AlertFullWidth` with `tintedBackground`, `hideDismissButton` and a padding override), so the settings are now one shared component, `PageBanner` (`app/pages/_shared/page-banner.tsx`), which Explore uses, and a new pattern page `/patterns/banners` documents it: a live example (closable), the rules (placement directly under the header and outside the scroll area, never in column 2 or floating; one fact and one step, the action named by where it goes; shown only to whom it is true, one per screen; colour by kind of notice; the corner icon as the only close control, closed for the visit; not for one record or section, which is the contained alert, nor for toasts or field errors), usage, and where it is used. Added to `lib/nav.ts` and the README pattern table (kept 1:1), and a line to `ref-shell.md`. The page says Explore's second layout carries the banner on its results page (checked live: it does not show in that layout's search state). No new component in `components/**`, so no 1.4 override; `AlertFullWidth` is unchanged. (2) The search-area rows in the floating card were two lines (name over "127.3 km radius · 0 records"); they are one line now, 42px a row instead of about 58. The type follows the design system's `Select.Item` name plus supporting text: both 14px, the name weight 500 in the primary text colour, the detail weight 400 in tertiary with tabular figures (the count changes), with no size step. The name truncates for a long one and the detail never does; the whole line is the tooltip. Measured live (`getComputedStyle`): name 14px / 500 / rgb(46, 41, 37), detail 14px / 400 / rgb(112, 107, 104) tabular-nums, one line, a 45 character name clipped with the detail intact; the tertiary colour against white is about 5:1. `/emil-typography` and `/emil-design-foundations` were applied: one size for the pair, hierarchy by weight and colour, no fake bold, figures that do not jiggle, truncation with the full text in the tooltip. Verified: tsc, eslint on the touched files, check:contracts, a live Playwright pass (docs page renders and closes; the Explore banner is the same 57px under the header for a signed-in role and for the public user, absent for BioData Admin; the rows). Open: Explore's second layout has no banner in its search state, only on results; whether it should match is for the designer. Not committed.
