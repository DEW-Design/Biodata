# 2026-10-30 - Privacy and restrictions: no restrictions is a state, not a dashed placeholder

- **Oct 30 2026: the Overview's "Privacy and restrictions" section, with no restrictions, shows an empty state like the rest of the page.** The designer, with a screenshot of it (a dashed box with one run-on line, "No restrictions. Everything in this project is openly available."): "this empty state needs to be improved as well." It was a bare paragraph in a dashed outline, the look of a placeholder, while the page's other empty states had become a card with an icon, a heading and a line (`2026-10-30-17`).
  - **Principles at stake (0.10):** 7 Design every state, 3 One system, 1 Say less. They agree.
  - **What changed (`project-tab.tsx`).** In the same solid card the page's other cards use, the compact empty state: an open-lock icon (`LockUnlocked01`), the heading "No restrictions" and the line "Everything in this project is openly available." The two sentences are the ones that were there, and the ones Add Project's "No restrictions" choice carries, so no wording is new; they are now a heading and a line. It has no button of its own: adding a restriction is the section's "Add restriction" button above it, and an action is not offered twice on one record (3.12). While the add form is open the empty state goes, since it would say there are none beneath a form that is making one. The heading is an h3 under the section's h2 (`ListEmptyState` takes an optional `headingLevel`; its default is as it was).
  - **Checked.** `npx tsc --noEmit`, `npx eslint` on the two files and `npm run check:contracts` pass. Live (Playwright, the draft Flinders Ranges Reptile Atlas, zero console errors): as BioData Admin the section shows the card and the "Add restriction" button once; as Public User the same card with no button; opening "Add restriction" removes the card; Adelaide Hills, which has restrictions, shows its restriction cards and no empty state.
  - **Not changed, found on the way.** The same dashed-box look is still in a few other places, none on the project page: the Taxonomy record's empty block (`tx-records.tsx`, which has its own button), the observation type's "No custom properties" box (`observation-detail`), and the Data ingestion stress test's empty panels. And the section's own subtitle, "What is held back from public release, and why.", is the kind of line `2026-10-30-20` removed from the tabs; it was left because it was not asked about.
  - **Open, for the designer (0.4).** (1) Should the section's subtitle go, as the tab intros did? (2) The empty state could carry the action itself ("Add restriction") and the header button could appear only once there is a restriction; that moves the action's place between states, which 4.2 and the page's notes warn against, so it was not done.
