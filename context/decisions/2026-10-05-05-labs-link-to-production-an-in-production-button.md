# 2026-10-05 - Labs link to production: an In production button on the Prototype tools bar

- **Oct 5 2026: Labs link to production: an In production button on the Prototype tools bar.** The designer: "once a decision has been folded into prod, can we have a way to route back to production for that particular page? ... a button to route me back to reports to see them live in production."
  - **What it is:** on a lab, the Prototype tools bar shows **In production** and the page's name (for `/proto/column-2`: "In production Template Finder"), after the tools and before the hide button. It opens the live page with the role being viewed kept (`?userRole=` carried over). It is a link (`next/link`), so it can be opened in a new tab, and a drag of the bar that ends on it does not follow it. A production page, which is not a lab, shows no such link.

The lab names are bare folder names, not `/proto/...` paths, so the 5.4 check (no `/proto` link outside the labs) stays satisfied.
