# 2026-10-01 - Every action button carries an icon

- **Oct 1 2026: Every action button carries an icon.** Page feedback on the DLA record page: the Approve button had no icon ("a weird way to do things"); add icons against buttons, work it in, and document it in the contracts. Sweep: of 257 labelled buttons under `app/pages`, about two thirds already had an icon and 51 filled or outlined ones did not (forms and their footers, modals, the auth flow, the registration flow, the field-notes composers, the home page, plus every `RecordAction` call site that omitted the optional `icon`: Start review, Approve, Reject and Resume review on DLA, DSA and nominations, and the status changes on User Management). Changes: `RecordAction.icon` is now required (so the compiler finds every record action); each of the 51 buttons has the glyph for its action, with forward-moving buttons (Continue, Go to project) using a trailing arrow; User Management's status changes carry their icon on the action definition (Activate and Enable `Power01`, Disable and Deactivate `PauseCircle`, Archive, Restore, Withdraw invitation) so a new one cannot compile without; `TextComposer` in field notes takes an `actionIcon`; the shared empty-state action takes `RefreshCcw01`. New clause CONTRACTS 3.12 (scoped to build in `rule-scopes.json`) with a one-icon-per-action table (Plus, ArrowRight, ArrowLeft, ArrowNarrowRight, XClose, Save01, Check, CheckCircle, XCircle, PlayCircle, PauseCircle, Power01, Archive, FlipBackward, SlashCircle01, Edit05, Trash01, Download01, Upload01, SearchLg, RefreshCcw01, LogIn01, UserPlus01, Key01, BarChart01, BookOpen01, Flag01, Link01), an action being a primary, secondary, tertiary or destructive `Button` with a text label; link-style buttons and icon-only buttons are not covered. New `AUTO §3.12` in `check-contracts.mjs`: it walks every file under `app/pages` (the auth flow and the home page included, which the shell rules skip) and fails any such button without an icon; proved with a temporary file (a bare primary and a default-colour button fail, while an icon button, a link button, an aria-label button and an ellipsis button pass) and then removed. The two stale unlinked drafts (`projects`, `projectsv2`) are exempt. Verified: tsc, eslint on the touched files, check:contracts; live as BioData Admin: the DLA record page (Approve has `CheckCircle`; the menu's Reject, Put on hold, Edit request and Cancel request all have icons), a User Management record, and a scan of nine screens (DLA, DSA, nomination, user, login, sign up, home, registration) found no boxed text button without an icon; the login and registration footers render cleanly; zero console errors. Open: the choices of glyph for actions the designer had not named (Save01 for save, Power01 for activate, Key01 for request access and reset password) are mine and sit in the contract's table for change in one place; Cancel now reads with an X and Save with a disk on every form; the standalone docs pages (`app/(docs)`) are outside the check.
