# 2026-10-02 - Option 2 pickers become quiet on-dark pills; Select gets an opt-in onDark

- **Oct 2 2026: Option 2 pickers become quiet on-dark pills; Select gets an opt-in onDark.** The designer said the Project and Dataset selects in the card (entry `-…-data-validation-error-report-project-and-dataset-selects`) "do not look good visually". Asked which direction, they chose "quiet pills on the card" over a single switcher button and over moving the fields back to the toolbar.
  - **What was wrong:** two full-strength white fields on the dark gradient outweighed the title, and the Dataset bar was 34rem of mostly empty white.
  - **Built:** in option 2 the two selects are small (`size="sm"`), content-sized pills in the card's first row, under their PROJECT and DATASET captions: a translucent white fill, a thin white ring, white value text with the file name at 70%, a 70% chevron, a stronger ring on hover, focus and open. The list that opens is the normal white popover. Project is at most 22rem and Dataset 30rem; the dataset ID shows in full and the file name is what truncates. Option 1 is unchanged.
  - **Component (1.6, additive):** `Select` has a new opt-in `onDark` prop (default false) that changes only the trigger's colours; every other caller renders exactly as before (checked: the Select doc page and the Species Detail and option 1 selects keep a white fill, the shadow and the 37px height). Documented in the Select doc page's API table.
  - **Verified:** `tsc`, `eslint`, `check:contracts`; live as BioData Admin: picking a project moves the dataset and facts, Escape keeps the value and focus returns, the narrow window stacks; zero console errors.
  - **Open:** which option stays; the typography skills were not re-run (the pill text is the Select's own `sm` text, white). Not committed.
