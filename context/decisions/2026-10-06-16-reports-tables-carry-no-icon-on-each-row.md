# 2026-10-06 - Reports tables carry no icon on each row

- **Oct 6 2026: the Reports landing's Table view put a featured icon at the left of every report's name; no other table in the app does. From the designer's screenshot: "inconsistency noted. Table view shouldn't have icons for each report?"**
  - **Why it was wrong (2.12, nothing on screen without a purpose):** an icon in a cell earns its place only when it tells the person something the text does not. Here the icon repeated the report's name in a different form, on every row, while the Category column already says what kind of report it is. The cards keep their icon: there it is the card's one picture, and the card has no other column to scan.
  - **Changed:** the All reports table shows the name over its one-line description, nothing to the left of it (`reports-landing.tsx`); the My reports table (`my-reports.tsx`, built earlier today with the same icon) is the same, the name alone. Both lose the now-unused icon plumbing (the My reports rows no longer carry the report's icon or description).
  - **Sibling grep:** no other `Table.Cell` in `app/pages` draws an icon beside a row's name. The `FeaturedIcon`s that turned up in the Nominations list, the DSA detail and the project's datasets view are an empty state, an empty state and a status snapshot card, not table rows, so they stay.
  - **Verified live (Playwright, 1708x1024, BioData Admin, Reports as Table):** 11 rows with the name, description, category badge, last opened and the "..." menu, no icon on the left; zero console errors. `tsc`, eslint on `app/pages/_shared/reports` and `check:contracts` pass.
  - **Open:** none new. First fix of this kind (0.8), so no `AUTO` check; one is due if a per-row decorative icon is found in a table again. Not committed.
